# fqtpx019 — Evidence Supply Chain & Independent Release QA

Status: project-local FQT skill contract.

## Purpose
Make every claim traceable to immutable commands, logs, results and hashes.

## Mandatory controls
- Store commands, timestamps, exit codes, raw logs, result archives and semantic ledgers.
- Scan secrets and keep all release configs keyless and stopped.
- Build SHA-256 manifests and verify ZIP CRC plus clean extraction.
- Never map workflow completion to scientific PASS without parsing native evidence.
- Require independent release review before OOS, dry-run or live authorization.

## Deliverables
Evidence manifest, receipts, source registry, secret scan, release review and rollback hashes.
